# FitTrack Pro User Guide (Mobile Dev 2)

## 1. Welcome

Welcome to **FitTrack Pro**. This app helps you:
- follow workout plans,
- get daily workout recommendations,
- receive workout reminders,
- track progress,
- and personalize app appearance.

This guide explains how to use each main feature quickly.

---

## 10. Quick Troubleshooting

### I do not receive notifications
- Ensure notification permission is granted.
- Ensure reminders are enabled in Profile.
- Try **Send test reminder now**.

### Recommendation says no plan available
- Create at least one workout plan in Workout tab.

### Theme does not change immediately
- Re-open Profile and select mode again.
- For Dynamic color, use Android 12+ device/emulator.
