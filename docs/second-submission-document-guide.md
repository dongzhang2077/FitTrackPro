## What you must submit for Submission 2

1. A zip file of your Android Studio project (current work).
2. A Word/PDF report document.

Important:

- Instructor must be able to download, unzip, and open your project in Android Studio.
- Late or missing-file submissions receive no credit.
- One upload chance only (no missing-file follow-up by email).

## Required content in the report document

Your report must include the following in order:

1. Your name and student ID.
2. Project title.
3. Runnable status of submitted project:
   - whether it compiles/runs in emulator.
4. If it does not compile/run:
   - exact reasons,
   - missing components/resources,
   - specific problems to fix.
   - Do not write vague statements like "not complete".
5. What has been done since proposal approval.
6. How completed work maps to original proposal and plan.
7. Any substantial implementation change and why.
   - Original approved app idea should not change.
   - Technology changes should be justified.
8. Remaining work to final submission.
9. Difficulties faced and design changes (if any).
10. Screenshots of implemented features (if applicable, strongly recommended).
